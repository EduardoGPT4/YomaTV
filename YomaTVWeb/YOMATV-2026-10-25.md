# YomaTV · Identidad y aplicaciones

Los proyectos son `YomaTVWeb` y `YomaTVAndroid`. Android 1.1.0 usa pantallas adaptadas al teléfono, una portada con estrenos y MAL, un horario con tarjetas horizontales, descargas por anime y un apartado Más completo. Cada pestaña Android conserva su propio WebView y pila de navegación, creados cuando se necesitan. Las pestañas ocultas suspenden su actividad y no se destruye el capítulo al cambiar de apartado.

El reproductor online conserva los controles originales de MP4Upload en el teléfono. La navegación entre episodios, el ojo manual de MAL y la descarga están debajo del video. Servidor y audio comparten una tarjeta. Los episodios indican actual/visto; la sinopsis y las escenas guardadas son desplegables. Se mantienen el reproductor local, los archivos interrumpidos y la sincronización pendiente del 80 %.

La nueva imagen proporcionada por el propietario se usa sin reinterpretarla: PNG web 32/48/180/192/512, favicon ICO, iconos Android por densidad y adaptativos, e ICO Windows 16–256. No se crea otro personaje.

## Actualizar sin perder datos

La identidad APK `app.seasonav1.mobile`, la firma original, las preferencias y SQLite se conservan expresamente. Las clases internas nuevas usan `app.yomatv.*`; dos adaptadores permiten que WorkManager siga resolviendo los trabajos antiguos. El código web mantiene el protocolo de colas, los nombres de cookies y la ruta pública `/seasonav1/`, incluidos el callback MAL registrado, las sesiones y el ámbito PWA. Son identificadores de compatibilidad; el nombre visible es YomaTV. Cambiar la ruta OAuth requeriría registrar y migrar otra URL en MAL.

La aplicación Windows se distribuye como `YomaTV.exe` con versión 2026.10.25.1. La carpeta de datos y la identidad de su tarea no se renombran para conservar la cola y evitar dos automatizaciones.

## Publicación de instaladores

Repositorio autorizado: https://github.com/EduardoGPT4/YomaTV. Se hizo público con autorización expresa del propietario. InfinityFree aloja la web; GitHub Releases aloja APK y EXE. Los límites de InfinityFree no permiten distribuir el EXE de unos 69 MB.

El workflow `.github/workflows/release.yml` compila Android y Windows, prueba el código, conserva la firma Android, publica los archivos y comprueba sus descargas anónimas mediante tamaño, formato y SHA-256. Se ejecuta con una etiqueta `v<versión Android>` o desde Actions. Las versiones existentes no se sobrescriben. Los secretos `ANDROID_KEYSTORE_BASE64` y `ANDROID_KEYSTORE_PASSWORD` se configuran cifrados en Actions, nunca en Git. El token de publicación de GitHub es efímero y pertenece al propio trabajo.

Para la siguiente versión: incrementar `versionCode`/`versionName` en Android y la versión de Windows si cambia, subir el código y publicar una etiqueta nueva. Los botones de la portada consultan la última release pública y muestran plataforma, versión y tamaño real. El JSON incluido en la web sirve de respaldo si GitHub limita temporalmente su API. Los enlaces estables del EXE usan la última release; no dependen de Google Drive.

El acceso al repositorio y la publicación están configurados con la cuenta GitHub existente; no se necesitan cuentas adicionales. El workflow requiere que los ejecutores de Actions estén disponibles para la cuenta.

Como alternativa, `release-tools/release.ps1` automatiza las mismas compilaciones, pruebas, publicación y verificación desde una PC con el entorno de desarrollo. Usa la sesión de Git Credential Manager o un token en la variable de entorno `GH_TOKEN`; no lo pide ni guarda en el código. `-PublishPrepared` publica los binarios ya compilados y comprobados. El código de la web obtiene los enlaces de Releases de la misma forma en ambos casos.


## Selección de audio en el reproductor

Los servidores se agrupan en filas independientes SUB, LAT (cuando existe) y DUB, con un icono de subtítulos o micrófono y el nombre del servidor sin repetir el idioma en cada botón. El botón seleccionado conserva su estado y el índice original al cambiar de fila o actualizar el listado; los idiomas que no están disponibles no crean filas vacías. La vista comparte estilos con Android 1.1.3 y no requiere instalar otro APK.

La prueba de selección comprueba filas intercaladas, LAT, cambio a DUB, actualización sin interrumpir el video y escape de etiquetas. La revisión visual usa datos sintéticos y estilos web/Android reales, en vistas de 320, 412 y 1280 px; no se reprodujeron capítulos ni se modificó una cuenta MAL real.
